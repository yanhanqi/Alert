# Power Grid Full Dataset Reconstruction

`power-grid-full` is a field-level electric power grid reconstruction of the lightweight `power-grid-minimal` scenario.

It is generated by:

```bash
conda run -n alertbert python scripts/build_power_grid_full.py
```

The generator reads `aitads_augmented/configs/power-grid-minimal.json`, transforms only the referenced alert fragments, writes them as `aitads_augmented/data/power-*.json`, and creates:

```text
aitads_augmented/configs/power-grid-full.json
```

The original AIT-ADS-A files are not modified.

## What Changes

Unlike `power-grid-minimal`, this configuration rewrites model-visible fields:

| Field | Change |
| --- | --- |
| `name` | Replaced with SCADA, IEC 61850, DNP3, PMU, and control-center alert text |
| `short` | Replaced with compact electric-grid alert tokens such as `DNP3-Recon`, `GOOSE-Hb`, `PMU-Exfil-End` |
| `host` | Replaced with power assets such as `substation_a_ied`, `control_gateway`, `pmu_gateway` |
| `ip` | Replaced with deterministic `10.66.x.x` control-network addresses |
| `time_label` | Replaced with power-grid event timing labels |
| `event_label` | Replaced with power-grid attack group labels |
| `hierarchical_event_label` | Rewritten as `event.stage.` so the existing loader can append the unique attack id |

## Attack Mapping

| Original fragment | Power-grid event label | Meaning |
| --- | --- | --- |
| `service_scan`, `dns_scan` | `substation_recon` | reconnaissance against SCADA/control-network services |
| `wpscan`, `dirb` | `ied_enumeration` | enumeration of IED, HMI, MMS, or gateway objects |
| `webshell_cmd` | `control_gateway_compromise` | unauthorized command execution on a control gateway |
| `crack_passwords`, `online_cracking` | `operator_account_attack` | operator credential brute force or cracking |
| `attacker_change_user` | `operator_role_switch` | unauthorized operator role switch |
| `escalated_sudo_command` | `control_privilege_escalation` | privilege escalation on a control host |
| `dnsteal_start`, `dnsteal_active`, `dnsteal_end` | `telemetry_exfiltration` | PMU, historian, or SCADA telemetry exfiltration |
| false positives | `-` | routine SCADA polling, GOOSE heartbeat, PMU batching, IED self-test, and monitoring noise |

## Usage

Load it with the existing dataset factory:

```python
from alertbert.aitads import AITAlertDataset

train = AITAlertDataset(split="train", configuration="power-grid-full")
val = AITAlertDataset(split="val", configuration="power-grid-full")
test = AITAlertDataset(split="test", configuration="power-grid-full")
```

Build ground-truth vocabularies before grouping evaluation:

```bash
conda run -n alertbert python -m alertbert.model_eval_utils power-grid-full
```

For MLM training, use `augment="power-grid-full"` in `MaskedLangModelParams`.

## Scope

This is still a synthetic reconstruction. It preserves the temporal offsets and alert counts of selected AIT-ADS-A fragments, but the visible cybersecurity vocabulary is rewritten into an electric power grid setting. This makes it suitable for lightweight application-scenario experiments without importing external power-grid datasets or copying the full AIT-ADS-A corpus.
